# 1c-career-compass

> Карьерный компас для 1С-разработчика. Junior → Middle → Senior → Lead → Architect → CTO.
> Матрица компетенций, чек-листы самооценки, шаблон IDP, анализатор разрывов.

Репозиторий с инструментами для планирования карьеры 1С-разработчика.
Помогает ответить на вопросы: где я сейчас, куда расти, что конкретно нужно подтянуть.

## Что внутри

- **Матрица компетенций** — три группы навыков (Hard, Soft, Business) с детализацией по шести грейдам
- **Чек-лист самооценки** — оценка себя по шкале 1-5 для каждого навыка
- **Шаблон IDP** — Individual Development Plan на 6 месяцев
- **Чек-лист повышения** — что проверить перед разговором о повышении
- **Визуализация карьерного пути** — ASCII-график изменения пропорций навыков
- **Анализатор разрывов** — топ-5 навыков с максимальным разрывом до целевого грейда

## Быстрый старт

```bash
git clone https://github.com/yourname/1s-career-compass.git
cd 1s-career-compass

# Визуализация карьерного пути
python3 scripts/visualize.py

# Анализ разрывов (укажите целевой грейд)
python3 scripts/skill-gap.py senior

# Шаблон самооценки
cat templates/self-assessment.md

# Шаблон IDP
cat templates/idp-template.md
```

## Шесть грейдов

| Грейд | Hard Skills | Soft Skills | Business Skills |
|-------|-------------|-------------|-----------------|
| Junior | 80% | 15% | 5% |
| Middle | 60% | 25% | 15% |
| Senior | 40% | 35% | 25% |
| Lead | 30% | 40% | 30% |
| Architect | 50% | 30% | 20% |
| CTO | 20% | 30% | 50% |

## Два трека после Senior

```
                   Senior
                      │
         ┌────────────┼────────────┐
         ▼            │            ▼
      Lead            │        Architect
      Управление      │        Техническая
      командой        │        стратегия
         │            │            │
         ▼            │            ▼
      CTO             │   Technical Director
```

- **Lead трек:** Senior → Lead → CTO. Отвечаю за людей, потом за бизнес.
- **Architect трек:** Senior → Architect → Technical Director. Отвечаю за технологии.

## Ключевые принципы

1. **Сертификации 1С — не грейды.** Они проверяют знание платформы, а не архитектуру, софт-скиллы, бизнес-компетенции.
2. **С ростом меняются пропорции.** Junior — 80% Hard Skills, CTO — 50% Business Skills.
3. **Performance review должен быть объективным.** Не «ты молодец», а «вот матрица, вот разрывы, вот план».
4. **IDP превращает «куда расти» в конкретный план** на 6 месяцев с измеримыми результатами.
