# Чек-лист для повышения грейда

## Перед разговором с руководителем

### Подготовка данных

- [ ] Проведена самооценка по всем группам навыков
- [ ] Определён целевой грейд
- [ ] Собраны конкретные примеры из работы за последние 6 месяцев
- [ ] Подготовлены метрики: что улучшилось благодаря моей работе
- [ ] Собрана обратная связь от коллег и заказчиков

### Соответствие целевому грейду

- [ ] Hard Skills соответствуют целевому уровню
- [ ] Soft Skills соответствуют целевому уровню
- [ ] Business Skills соответствуют целевому уровню
- [ ] Пропорции навыков совпадают с целевым грейдом

### Достижения

- [ ] Реализованы проекты уровня целевого грейда
- [ ] Есть измеримые результаты (метрики, экономия)
- [ ] Есть примеры менторства или лидерства
- [ ] Есть примеры самостоятельных архитектурных решений

### Готовность к новым обязанностям

- [ ] Понимаю что изменится в работе на новом грейде
- [ ] Готов к новым обязанностям
- [ ] Есть план развития после повышения
- [ ] Понимаю зону ответственности

## Во время разговора

### Что сказать

- [ ] «За последние 6 месяцев я сделал [конкретные проекты]»
- [ ] «По матрице компетенций я соответствую целевому грейду: [примеры]»
- [ ] «Вот метрики моей работы: [цифры]»
- [ ] «Вот обратная связь от коллег: [цитаты]»
- [ ] «Хочу обсудить повышение и план на следующие 6 месяцев»

### Что спросить

- [ ] «Что ещё нужно чтобы соответствовать грейду?»
- [ ] «Какие конкретные шаги я могу сделать в ближайший месяц?»
- [ ] «Когда мы можем вернуться к этому разговору?»
- [ ] «Какой бюджет развития вы можете выделить?»

## После разговора

### Если повысили

- [ ] Поблагодарить
- [ ] Составить новый IDP
- [ ] Обсудить новые обязанности
- [ ] Продолжить развитие

### Если отложили

- [ ] Спросить конкретные критерии
- [ ] Зафиксировать план
- [ ] Назначить дату следующего разговора
- [ ] Не опускать руки — продолжить работу

### Если отказали

- [ ] Спросить причины
- [ ] Оценить реалистичность плана
- [ ] Подумать о смене команды или компании
- [ ] Не воспринимать как личное поражение

## Красные флаги

Если на ваш запрос о повышении:
- [ ] Говорят «ты молодец, но...» без конкретики
- [ ] Не могут назвать критерии
- [ ] Откладывают без назначения даты
- [ ] Меняют критерии каждый раз
- [ ] Предлагают повышение без повышения зарплаты

**Это повод задуматься о смене работы.**
